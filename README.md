# 名城大学キャンパス 3Dモデル

名城大学・天白キャンパス周辺の3Dモデルを含む Unity プロジェクトです。

## 開き方

1. Git と Git LFS をインストールします。PLATEAU SDK の取得に使います。
2. このリポジトリをクローンし、Unity Hub の「追加」でリポジトリのフォルダを選びます。
3. Unity 6000.4.0f1 で開き、パッケージの解決が完了したら Assets/Scenes/SampleScene.unity を開きます。

## データ出典

出典は国土交通省 Project PLATEAU の [3D都市モデル 名古屋市（2022年度）](https://www.geospatial.jp/ckan/dataset/plateau-23100-nagoya-shi-2022) の CityGML（v4）です。キャンパス周辺を Unity に取り込み、シーンとして保存しています。データの利用条件は [PLATEAU のサイトポリシー](https://www.mlit.go.jp/plateau/site-policy/) を参照してください。

[PLATEAU SDK for Unity v4.3.0](https://github.com/Project-PLATEAU/PLATEAU-SDK-for-Unity/releases/tag/v4.3.0) は Unity Package Manager が公式リポジトリから取得します。
